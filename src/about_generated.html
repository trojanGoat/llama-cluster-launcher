Llama Cluster Launcher

v1.0.0

A GUI launcher for llama.cpp clustered inference, enabling distributed model serving across a node0 node and SSH-connected node nodes.

Getting Started

  1. Ensure llama.cpp is compiled on all nodes.
  2. Configure SSH access from the node0 to your node nodes.
  3. Launch the app and enter your cluster details (node0 IP, node IPs, SSH credentials).
  4. Select a model and click Start Cluster to deploy inference services.
  5. Use the provided endpoint to send inference requests.
