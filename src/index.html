Llama Cluster Launcher

v1.1.1-beta

A GUI launcher for llama.cpp clustered inference, enabling distributed model serving across a master node and SSH-connected worker nodes.

Getting Started

  1. Ensure llama.cpp is compiled on all nodes.
  2. Configure SSH access from the master node to your worker nodes.
  3. Launch the app and enter your cluster details (master IP, worker IPs, SSH credentials).
  4. Select a model and click Start Cluster to deploy inference services.
  5. Use the provided endpoint to send inference requests.

For more information, visit the GitHub repository.
