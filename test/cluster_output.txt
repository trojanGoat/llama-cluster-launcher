Can you write a simple Python function to calculate the nth Fibonacci number?

--- Response ---
Certainly! Here's a simple and efficient Python function to calculate the nth Fibonacci number using an iterative approach:

```python
def fibonacci(n):
    """
    Calculate the nth Fibonacci number.

    The Fibonacci sequence starts with:
    F(0) = 0
    F(1) = 1
    F(n) = F(n-1) + F(n-2) for n > 1

    Parameters:
        n (int): The position in the Fibonacci sequence (0-indexed)

    Returns:
        int: The nth Fibonacci number

    Raises:
        ValueError: If n is negative
    """
    if n < 0:
        raise ValueError("n must be a non-negative integer")
    if n == 0:
        return 0
    if n == 1:
        return 1

    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

### Example Usage:
```python
print(fibonacci(0))   # 0
print(fibonacci(1))   # 1
print(fibonacci(5))   # 5
print(fibonacci(10))  # 55
```

### Notes:
- This iterative solution is efficient with a time complexity of O(n) and space complexity of O(1).
- For educational purposes, a recursive approach is possible but much less efficient due to repeated calculations.
